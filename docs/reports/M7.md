# M7 自动收件箱与 AI 整理

2026-11-01。用户选择「安装 Hammerspoon + 截图自动入库」，并要求自动入库后由 AI 归纳。

## 目标与边界

- 系统截图（`⇧⌘4` / `⇧⌘5`）保存到收件箱后自动进入 NOESIS，不需要额外快捷键。
- 入库时按内容哈希去重，保留原图、OCR、Markdown，并进入日报。
- OCR 完成后，可选调用官方 DeepSeek 生成标题、摘要、标签和分类；默认关闭。
- 所有处理在本机完成；只有整理文字会经既有 `digest/client.py` 发出，截图图片不上传。

## 实现

### 收件箱

- `[capture] watch_dirs = ["inbox"]`、`auto_import = false`；相对路径位于数据目录内。
- `noesis/capture/inbox.py`：哈希去重、复制到 `captures/YYYY-MM/`、写入事件与 Markdown、
  后台触发既有 OCR。原文件在数据库写入成功后才删除，先复制后删除避免入库失败丢图。
- `noesis import-inbox [--wait 1] [--limit 50]`：扫描监听目录；忽略隐藏文件、非图片、
  空文件和刚写入的文件；`run/inbox.lock` 防止并发重复扫描。
- `com.justin.noesis.inbox` launchd 任务使用 `WatchPaths` + 300 秒兜底，安装时创建监听目录；
  关闭 `auto_import` 后安装会移除旧 plist。
- 自动导入的标题使用文件名；系统截图文件名会转成「截图 YYYY-MM-DD HH:MM」。

### AI 整理

- `noesis/organize.py`：输入标题、应用、网址、备注和截断后的正文；提示词要求严格 JSON，
  并声明输入中的指令不得执行。
- 校验标题（≤80）、摘要（≤300）、标签（数量与长度）、分类枚举（读/工具/灵感/证据/其他）
  和建议项目（≤60）；标签去重、去掉 `#`。
- `meta.tags`、`meta.category`、`meta.ai` 写入数据库；标题替换原文件名标题；Markdown
  front matter 和正文增加标签、分类与摘要；日报的收藏行追加 `#标签`。
- `project` 只作为建议展示，不自动改写事件项目，避免模型猜测污染项目统计。
- 仅在 `[organize] enabled = true` 时调用；失败写入 `ai_status=failed`，保留原收藏与标题。
- 凭证沿用 `DEEPSEEK_API_KEY` 或数据目录 `.env`，不新增钥匙串依赖；日志只记录状态、标签数和用量。

### 修复

- 已证实 bug：后台 OCR 子进程原先用 `python -m noesis`，在 launchd 从 `noesis.pyz` 启动、
  工作目录不在代码仓库时会报 `No module named noesis`，导致安装态的收藏永远停在
  `ocr_status=pending`。现在 `enrichment_command` 在入口为 `.pyz` 时用
  `python -I <pyz> capture-ocr`，源码模式仍用 `-m noesis`。

## 已知限制

- 只扫描监听目录的第一层，不递归子目录。
- 自动收件箱会导入目录内所有支持的图片；没有忽略规则、暂停开关或删除命令。
- AI 只按单张收藏整理，不做跨收藏的合并归纳；标签目前供 Obsidian 和日报浏览，
  `noesis search` 仍只检索标题、正文和 URL。
- 摘要与标签依赖 OCR/网页文字质量；图片本身不参与判断。
- 模型调用按张计费，默认 `low` 思考档；可在 `[organize]` 调整或关闭。
