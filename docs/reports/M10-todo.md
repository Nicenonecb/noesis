# M10 待办表格与关联文件夹

2026-11-09。分支 `feature/todo-board`（基于 `feature/dsh-collector` 的 `5eeda28`）。
按用户要求增加类似飞书多维表格的待办视图，区别在于任务可以关联本机文件夹。

## 功能

- `noesis todo`（或 `noesis todo serve`）在 `127.0.0.1` 启动本机页面并打开浏览器；`--port` 固定端口，
  `--no-open` 只打印地址。`noesis todo list`、`noesis todo add 标题 --tag … --folder 路径` 供命令行使用。
- 表格列：任务名称、任务标签（重要紧急 / 重要不紧急 / 紧急不重要 / 不重要不紧急）、状态、任务类别、
  解决办法/备忘、**关联文件夹**、任务耗时、更新时间、创建时间、父记录。
- 按状态（未开始 / 进行中 / 已完成）分组，可折叠并显示记录数；首列冻结，横向滚动；
  子任务可展开，父行显示 `↳ 数量`；单元格点击即编辑，标签和状态用下拉选择，类别提供已有值补全。
- 关联文件夹：点击 ＋ 弹出 macOS 原生选择框；点击文件夹在访达中打开；悬停可取消关联。
  若该目录属于 NOESIS 已知项目，提示中显示项目名和最近一次活动时间；目录被删后显示删除线。
- 任务耗时：未完成按创建至今，已完成按创建至完成时间；重新打开任务会清除完成时间。
- 支持搜索（名称、类别、备忘、文件夹路径）、勾选批量删除；删除会连同子任务一起删除并先确认。

## 实现

- `noesis/todo.py`：数据存放在数据目录 `todos.json`，沿用 `focus.json` 的文件锁 + 原子替换（0600）。
  文本字段复用 `focus._text` 校验并经 `redact` 脱敏；文件夹必须是已存在的绝对路径，去重，最多 10 个。
- `noesis/todo_server.py`：标准库 `ThreadingHTTPServer`，仅监听回环地址。每次启动生成随机令牌：
  页面需 URL 令牌，API 需 `X-Noesis-Token` 请求头，并校验 `Host` 为 `127.0.0.1:端口`，
  阻止其他网页跨站调用或 DNS 重绑定。只能打开已关联到任务的文件夹，不接受任意路径。
  请求日志关闭，避免令牌出现在终端或日志中。不发起任何外部网络请求，也不调用模型。
- `noesis/todo_page.py`：单文件页面以 Python 字符串保存，保证 `noesis.pyz` 运行包能携带；
  页面全部用 `textContent` 构建 DOM，不拼接用户文本到 HTML。展开/折叠状态存于 `localStorage`，失败时忽略。

## 桌面应用（M10.1）

用户提出改用 Electron 以免来回切终端；比较后选择原生 Swift（用户确认）：与晨报窗口同一套技术，
约 110 KB，不引入 Node/npm，安装脚本仍可离线运行。

- `noesis/todo_app.swift`：程序坞应用，启动运行包的 `noesis todo --no-open --exit-on-stdin-eof`，
  从标准输出读取带令牌的地址后在 WKWebView 中加载；只允许该地址的导航，外部链接交给默认浏览器。
  提供编辑菜单（WKWebView 输入框依赖它支持 ⌘C/⌘V/⌘A/⌘Z），实现 `confirm` 对话框
  （否则删除确认恒为“取消”），关联文件夹改用原生 `NSOpenPanel`，经消息通道回传页面。
- 服务进程持有应用传入的 stdin 管道；应用退出或崩溃导致管道关闭时，服务随之停止，不残留端口。
- `install.py`：每次安装编译到 `~/Applications/NOESIS 待办.app`（不依赖晨报开关）并临时签名、注册；
  卸载时仅在 Bundle ID 为 `com.justin.noesis.todo` 时删除该应用，避免误删同名应用。

## 已知限制

- 命令行方式下页面需要终端中的 `noesis todo` 进程保持运行；桌面应用无此问题。
- 消息在生成日报时已被截断到 120/300 字，应用里只能显示截断后的内容。
- 修改源码后需重新运行 `scripts/install.sh`，应用使用的是数据目录中的运行包。
- 应用暂无自定义图标。
- 窗口宽度小于约 1360px 时表格仍会超出，可以横向滑动，但不显示滚动条。
- 分组固定为三种状态，暂不支持自定义列和新建分组。
- 待办尚未接入晨报或日报。
