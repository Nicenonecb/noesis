# M6 DeepSeek 晨报与解锁展示

日期：2026-10-26。比较基线：5653889。按用户后续指示实施，不再局限于 M1–M5。
写后审查使用 post-code-review；后台故障定位使用 diagnosing-bugs；中文提交推送沿用 git-commit-push-zh。

## 产品行为

- 本机只启用 Chrome 历史采集；保留 Claude Code、Codex、Git。
- 每天系统时间 00:30 总结前一天完整自然日，本机核实为 +0800 / Asia/Shanghai。
- 不设固定 09:00 提醒。按用户修正，在当天解锁/登录后打开本地晨报窗口；首次安装可展示已有晨报。
- 分为昨日成果、进行中、未完成与待确认、今日建议（最多 3 项），每条引用输入证据编号。
- JSON/Markdown/HTML 均按展示日保存在数据目录 briefings，不进入代码仓库。
- 当夜休眠/关机时，恢复后补最近一个完整自然日，原始日志补 7 天。
- 成功按日期缓存，不重复调用；修改源码后重新安装才更新后台独立运行包。
- 网络/服务故障最多 3 次生成尝试，间隔 30 分钟；实际解锁可额外恢复一次临时故障。
  每次 HTTP 尝试仅在 429/5xx 时即时补发一次；401/402/403 不盲目重试。
- 窗口完成页面加载后才确认已展示。重复检查、解锁、任务重启不会在同一天再次展示成功晨报。

## 模型与数据边界

[DeepSeek 官方说明](https://api-docs.deepseek.com/)在本次核验时将 `deepseek-flash`
映射到 DeepSeek-V4.1-Flash-1017。实际模型列表和合成请求均成功；响应 model 字段为 deepseek-flash。
使用官方滚动别名，不声称永久固定供应商底层版本。

Key 按用户最新要求改用 DEEPSEEK_API_KEY 环境变量或数据目录 .env（0600）；不再读取钥匙串。
隐藏输入设置 Key，未写入源码、TOML、模型输入或日志。初版钥匙串方案及排查记录保留在后文。
请求只发往官方域名，禁止 HTTP 重定向转发 Authorization。
输入只含筛选、截断、脱敏的活动文字，不附带原始文件定位字段或图片，不上传完整数据库。
默认最多 240 条/60000 字符，按项目和来源轮流选取；晨报显示遗漏数量。
模型无工具权限，输出结构与引用编号必须通过校验；Markdown 正文解析排版，原始 HTML 转义，禁止脚本与远程资源。
这些规则不能证明模型判断必然正确，完成状态与今日建议仍供用户核对。
