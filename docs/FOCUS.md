# 关注方向与主动跟进

设置一个你想发展的方向，再约定一个可执行的小行动。NOESIS 从次日开始，在每日解锁晨报的顶部主动追问进展。
最多同时启用 3 个方向，避免提醒过多。当天没有反馈，后续晨报仍会继续跟进；不会把缺少记录等同于没有行动。

## 使用前提

使用现有的晨报功能：数据目录 `config.toml` 的 `[digest] enabled = true`，按项目既有方式配置 DeepSeek Key，
运行 `scripts/install.sh` 更新后台运行包与晨报窗口。默认仍为关闭，不因设置方向自动开启联网或安装后台任务。
默认 00:30 生成前一天总结，在次日解锁/登录后展示，每天成功晨报只展示一次。
这是本机 macOS 展示；手机推送属于后续规划。

## 在晨报窗口中设置和反馈

1. 点击顶部的「＋ 设置关注方向」，填写名称、发展方向和一个具体行动。
2. 次日到期时，晨报主动展示该方向、行动、最近反馈及可用的 AI 建议。
3. 点击「完成了」「还没完成」可补充简短反馈；「明天再提醒」延后一天；「暂停此方向」停止跟进。

保存后立即更新本地页面，不额外调用模型。完成的是当天行动，长期方向会在下一天继续提醒。
系统仅记录你的明确反馈；AI 建议不会替你打卡、改计划或判断长期目标已经完成。
按钮仅在 NOESIS 原生晨报窗口内生效；普通浏览器、Markdown 和历史晨报用于查看。

## 命令行管理

以下均为合成示例；将命令返回的 ID 替换到后续命令中：

```sh
noesis focus add --title "表达练习" --direction "把复杂问题讲清楚" --step "花十分钟写一段解释并朗读"
noesis focus list
noesis focus update <ID> --step "先写三句话说明一个问题"
noesis focus checkin <ID> --outcome done --note "完成了今天的小行动"
noesis focus checkin <ID> --outcome missed --note "行动太大，明天缩小范围"
noesis focus checkin <ID> --outcome snoozed --until 2026-11-05
noesis focus pause <ID>
noesis focus resume <ID>
```

`--until` 必须晚于操作当天；省略时延后到明天。同一天再次反馈会替换当天记录，保留最近 30 个日期的反馈。
自定义数据目录可使用 `noesis --data-dir /绝对路径 focus ...`。
设置、修改、暂停和反馈可离线进行；恢复后从次日开始提醒。历史报告不提供操作按钮。

## 数据与失败处理

方向和反馈保存在数据目录的 `focus.json`，权限 0600，写入使用文件锁和原子替换；敏感模式沿用已有脱敏规则。
AI 晨报启用时，将到期方向、具体行动及最近一次本人反馈随活动摘录交给既有官方 API；不会上传完整反馈历史。
模型建议必须通过方向 ID、证据编号、长度和去重校验。修改方向或反馈后，与旧版本绑定的模型建议立即失效。

没有活动记录时，使用本地行动和追问，不调用模型；模型失败时，错误页仍显示本地跟进及反馈按钮。
每日展示、重试和确认沿用现有晨报机制；休眠期间不会承诺准点弹出，恢复后由既有调度补触发。
